Logic Proposition Agent

Unification is the engine behind automated reasoning. Prolog and resolution-based theorem provers depend on it to decide when two logical statements can be made identical. This agent takes two first-order logic statements written in Backus-Naur form and returns their most general unifier: the simplest set of variable substitutions that makes the statements match.

The agent parses each statement into a structured term tree, walks both trees side by side, and binds variables as it goes. When two structures clash, it reports that no unifier exists.

CRUD Database

Bits-N-Fixels is the theoretical backend of a gaming review website. I built it as the final project for CS340 to practice designing a relational database and wiring it to a working application from schema to screen.

A NodeJS server runs SQL queries against a MySQL database and passes the results to Handlebars templates that render each page. A simple web UI exposes the full create, read, update, and delete cycle, so every operation can be tested from the browser.
